 Sales Performance Dashboard
## Project Overview
This project analyzes sales data using Power BI.
The project includes data cleaning, data modeling, DAX analysis, and an interactive dashboard.

## Project Workflow
- Data Cleaning
- Data Modeling
- Data Analysis using DAX
- Interactive Dashboard

## Dashboard Features
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Sales Over Time
- Sales by Branch
- Top 10 Products by Sales
- Orders by Category

## Tools Used
- Power BI
- DAX
